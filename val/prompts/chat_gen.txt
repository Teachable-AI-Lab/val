We are going to perform an iterative process together. In each iteration, I will provide you with:
1. A **phrase** describing an action.
2. A **verb** extracted from the phrase, which will serve as the predicate.
3. A **list of objects** that can be used as arguments.

Your task is to:
- Form a **predicate-argument structure** using the verb as the predicate.
- Select a subset of the objects from the list to use as arguments for the predicate.
- If the list of objects is empty, you do not need to include any arguments.

**Important Notes**:
- The first argument (e.g., `player`) represents the agent performing the action.
- Only include arguments that are relevant to the action described by the phrase.
- Avoid including arguments that are constant and will never vary (e.g., the pot in the "cook" action).
- Respond only with the predicate-argument structure. Do not include any additional words or explanations.
